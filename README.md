# Auspify Technologies – Data Analysis Internship

**Python Data Analysis Projects | Internship Portfolio**

## About This Repository

This repository contains four data analysis projects completed as part of my Data Analysis Using Python Internship at Auspify Technologies.

The projects focus on data cleaning, exploratory data analysis, data visualization, and extracting meaningful insights from the Netflix dataset using Python.

## Projects

### 1. Netflix Data Cleaning & Preparation
- Cleaned and prepared the Netflix dataset.
- Handled missing values and duplicate records.
- Standardized text data and prepared a clean dataset.
- **Dataset:** 8,790 records and 10 columns.
- [View Project](./Task_01_Netflix_Data_Cleaning/)

### 2. Netflix Content Type Analysis Dashboard
- Analyzed the distribution of Movies and TV Shows.
- Created bar charts, pie charts, and comparison visualizations.
- Developed a combined analysis dashboard.
- **Key Finding:** Movies account for 69.69% of the content.
- [View Project](./Task_02_Content_Type_Analysis/)

### 3. Netflix Country-Wise Content Analysis
- Analyzed Netflix content distribution across countries.
- Compared Movies and TV Shows by country.
- Identified countries with the highest content production.
- **Key Finding:** The United States has the highest content count, followed by India.
- [View Project](./Task_03_Country_Wise_Analysis/)

### 4. Netflix Release Year Trend Analysis
- Analyzed Netflix content releases across 74 release years.
- Compared Movie and TV Show release trends.
- Identified the top 10 release years.
- Created a combined trend analysis dashboard.
- **Key Finding:** 2018 recorded the highest number of releases with 1,146 titles.
- [View Project](./Task_04_Release_Year_Trend_Analysis/)
