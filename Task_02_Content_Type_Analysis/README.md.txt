# Netflix Content Type Analysis Dashboard

## Project Overview
This project focuses on analyzing Netflix content using Python. It compares Movies and TV Shows based on their total count, percentage distribution, and content ratings.

## Project Objectives
- Analyze the distribution of Movies and TV Shows.
- Calculate content type percentages.
- Compare content ratings between Movies and TV Shows.
- Create visualizations and a combined dashboard.
- Extract meaningful insights from the dataset.

## Dataset Information
- **Dataset:** Netflix Cleaned Dataset
- **Total Records:** 8,790
- **Total Columns:** 10
- **Content Types:** Movies and TV Shows
- **Missing Values:** 0
- **Duplicate Records:** 0

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis and Visualizations
1. Movies vs TV Shows Count Analysis
2. Content Type Percentage Distribution
3. Bar Chart and Pie Chart
4. Seaborn Count Plot
5. Content Ratings Comparison
6. Rating Percentage Analysis
7. Combined Netflix Content Dashboard

## Key Findings
- Total Movies: 6,126 (69.69%)
- Total TV Shows: 2,664 (30.31%)
- Movies represent the majority of Netflix content.
- TV-MA is the most common rating for both content types.
- TV Shows have a higher percentage of TV-Y and TV-Y7 ratings compared to Movies.

## Conclusion
The analysis highlights the distribution of Movies and TV Shows on Netflix and compares their rating patterns using Python visualizations.
