# Netflix Country-Wise Content Analysis

## Project Overview
This project analyzes Netflix content based on country-wise distribution. It compares Movies and TV Shows across different countries using Python.

## Project Objectives
- Identify top countries by Netflix content.
- Analyze country-wise Movies and TV Shows.
- Compare content distribution across countries.
- Identify top 10 countries separately for Movies and TV Shows.
- Create visualizations and meaningful insights.

## Dataset Information
- **Dataset:** Netflix Cleaned Dataset
- **Total Records:** 8,790
- **Total Columns:** 10
- **Countries Analyzed:** 85
- **Missing Values:** 0
- **Duplicate Records:** 0

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis and Visualizations
1. Top 15 Countries by Netflix Content
2. Country-Wise Movies vs TV Shows Comparison
3. Top 10 Countries by Movies
4. Top 10 Countries by TV Shows
5. Country-Wise Summary Analysis
6. Combined Country-Wise Analysis Dashboard

## Key Findings
- United States has the highest number of Netflix titles.
- India ranks second in total content.
- United States leads in both Movies and TV Shows.
- India has 92.34% Movies.
- Pakistan has 83.14% TV Shows.
- Japan and South Korea have a strong TV Show distribution.

## Conclusion
This project provides insights into Netflix's country-wise content distribution using Python data analysis and visualization techniques.
